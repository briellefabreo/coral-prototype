# CORAL — Professional Static Website Prototype

A polished, responsive single-file website prototype for the Community Rescue and Alert Link (CORAL), a school research project focused on community information in Corcuera, Romblon.

## Files
- `index.html` — complete website with its CSS and JavaScript included.
- `README.md` — publishing and limitation notes.

No React, Node.js, external libraries, or build process is required.

## Replace the old prototype
1. Open your new GitHub repository.
2. Open `index.html` and click the pencil icon to edit, or upload this new `index.html` and choose to replace the existing file.
3. Commit the changes to the `main` branch.
4. Keep GitHub Pages configured as **Deploy from a branch → main → /(root)**.
5. Refresh your published site. If the old version remains, open it in a private/incognito tab or clear the browser cache.

## Features in this prototype
- Responsive layout for desktop and mobile
- Overview cards and navigation by category
- Search and category filtering
- Sample notices for power interruptions, sea travel, and disaster advisories
- Demonstration administrator form for adding local sample notices
- Larger text and high-contrast display settings
- Print-friendly layout

## Important limitations
This is a static front-end demonstration. All notices are sample content. The administrator form changes data only in the current page session; it does not save to a shared database or publish to other visitors. It does not send push notifications or receive live updates. Before real-world use, the project needs an approved data source, secure administrator authentication, a shared backend/database, and a verified update procedure.
