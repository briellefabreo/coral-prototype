# CORAL — Community Rescue and Alert Link

This is a simple, self-contained static website prototype for a school research project about community information in Corcuera, Romblon.

## Files
- `index.html` — the complete website (HTML, CSS, and JavaScript in one file).
- `README.md` — these instructions.

No Node.js, React, build step, or additional assets are required.

## Publish with GitHub Pages
1. Create a **new public repository** on GitHub. For example: `coral-prototype`.
2. Upload `index.html` and `README.md` directly to the repository's **root** (not inside another folder).
3. Click **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two and open the Pages URL shown in Settings → Pages.

If your repository is named `coral-prototype`, the URL normally looks like:
`https://YOUR-USERNAME.github.io/coral-prototype/`

## Important prototype limits
- The notices are demonstration/sample content, not live official alerts.
- The administrator form changes the page in the current browser only. It does not send notifications, save to a shared database, or update other visitors' pages.
- Replace sample content with verified information only when the project has an approved source and update procedure.
